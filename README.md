# humanize-stories

Скіл для Claude, з яким нейромережа пише історії по-людськи на рівні **структури сюжету**, а не лише слів.

В основі — дослідження [StoryScope](https://arxiv.org/abs/2604.03136) (University of Maryland + Google DeepMind, COLM 2026). Дослідники розібрали 61 608 історій від людей і п'яти моделей. З'ясувалося, що ШІ-текст можна впізнати з точністю 93% лише за тим, як побудована історія. Навіть після чистки стилю.

## Що робить скіл

- Дає Claude **7 правил**, де ШІ найсильніше відрізняється від людини: не пояснювати мораль, ламати пряму лінію, додавати побічні сюжети, не давати героєві все вирішувати самому, називати почуття прямо, говорити з читачем, обирати нетиповий хід.
- **Аудит із 10 питань**: перевіряє готовий текст і показує, що переписати.
- **Поправки на "почерк" моделі**: Claude, GPT, Gemini, DeepSeek, Kimi.
- Підходить для історій, сторітелу в постах, сценаріїв рілсів, листів-історій.

## Встановлення

**Claude Code**

Скопіюй папку `humanize-stories` у `~/.claude/skills/`:

```bash
git clone https://github.com/wladlushprod-web/humanize-stories.git
cp -r humanize-stories/humanize-stories ~/.claude/skills/
```

**Claude.ai / застосунок Claude**

1. Завантаж репозиторій (Code → Download ZIP) і заархівуй окремо папку `humanize-stories`.
2. Відкрий Settings → Capabilities → Skills і завантаж архів.

## Як користуватися

Просто попроси Claude написати або переписати історію:

> Перепиши цю історію по-людськи

> Напиши сценарій рілса-історії про те, як я звільнився з офісу

> Чому цей текст звучить як ШІ? Зроби аудит

Скіл підхопиться сам.
